# CHANGED
`writeWaveform`, `withWaveform`, `simulateWaveform` and `recoverWaveform`
refuse a path that cannot be meant, before anything runs, with an error that
says what to give instead: an empty path, a path that names a directory (it
ends in a separator, `.` or `..`), and a path that already ends in `.fst`,
`.vcd`, `.json` or `.spill`. Before, an empty path wrote
`<parent>/<name of the working directory>.fst`, a directory got hidden files
named `.fst`, `x.fst` became `x.fst.fst`, and `recoverWaveform` given
`x.spill` looked for `x.spill.spill`. `recoverWaveform` gives the refusal as
a `Left`; the others throw it, as they throw for a bad window.
