# ADDED
A recording can keep its values in memory (`spill = InMemory`), so that
nothing is written to disk but the waveform. With `spill = OnDisk`, a run that
is stopped (a cancelled test, a killed process) keeps its spill file, which
now describes itself: `recoverWaveform` (or `recoverRecording`) writes the
waveform of what the run recorded. A cancelled run writes everything it
recorded; a killed one, everything up to about a second before.
