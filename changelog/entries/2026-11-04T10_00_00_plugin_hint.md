# CHANGED
When a module uses the generic path of `Traceable` (an empty instance, or
`traceNamed` by hand) without the plugin, the compile error now says how to
fix it: `TurnOnThePlugin "add -fplugin=Clash.CircuitContext.Plugin …"`.
Before, it named only internals (`AutoTrace`, `CanTrace`, `$dmtraceNamed`).
