# CHANGED
The waveform of a failing run is marked in its `.json` sidecar, under the key
`clash-circuit-context`, which a viewer ignores. A passing `withWaveform`
reads only the sidecar to tell a failure's waveform from one written on
purpose. Before, it read the waveform: libfst's reader could crash the test
process on an FST that was cut off.
