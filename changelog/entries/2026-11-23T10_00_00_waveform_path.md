# CHANGED
`writeWaveform`, `withWaveform`, `simulateWaveform` and `recoverWaveform`
take the waveform's path, without extension, where they took a name under
`waveforms/`: `"waveforms/counter"` writes `waveforms/counter.fst` and its
`.json` sidecar, and the spill file is `waveforms/counter.spill`. The path is
relative to the working directory or absolute, and missing directories are
made. A path whose directory cannot hold the waveform (a part of the path is
a file, or a directory is not writable) is refused before the design runs,
with either `spill` option, by an error that names that part by its absolute
path: `<dir> is a file, not a directory`, `<dir> is not writable`.

```hs
writeWaveform defaultOptions "waveforms/counter" (0, 100) dut
```
