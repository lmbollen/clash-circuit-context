# FIXED
The message of a waveform function for a window that shows nothing names the
window in the cycles the caller gave, as `(start,stop)`, and the end of the
run as a cycle. Before, it gave both in units of the recording's timescale,
which differ from cycles when the design has more than one domain: a window
`(5, 5)` of a 15 ns domain beside a 10 ns one was "the window [15, 15)".
The message of `writeVCD` and `writeFST` for a window that starts at the end
of the run says "at or after" it.
