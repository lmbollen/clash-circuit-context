# FIXED
Two recordings that use one spill file at the same time no longer crash. A
recording now locks its spill file, and a second recording with that file
(in the same process, as tests that run in parallel do, or in another)
throws at once an error that names the file. Before, the second one
truncated the file that the first one wrote through memory mappings, and
the first one died with SIGBUS, taking the whole process (a test suite with
all its tests) with it, without a message.
