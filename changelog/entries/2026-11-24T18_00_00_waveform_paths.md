# FIXED
Every message names a waveform or a spill file by its absolute path, also
when the caller gave a relative one. Before, some messages (no waveform
written, the failure did not happen again, a full disk) named the path as
given, relative to a working directory that differs between ways of running
a suite.

# FIXED
`AtSize` keeps one case per waveform path, however the path is spelled:
`waveforms/p` and `./waveforms/p` are one path. Before, they were two, and
the second property wrote the same files again.

# CHANGED
One path is one waveform: writing a waveform in one format deletes a waveform
of the other format at that path. The two share the `.json` sidecar, which
describes the waveform written last.
