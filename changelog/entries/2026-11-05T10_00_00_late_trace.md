# FIXED
A trace that the simulation first evaluated when the run ended has the
cycles that were evaluated in the waveform, its last one too. Before, its
last cycle showed as `z`, and a trace that it reached in turn was not in the
waveform. When a run ends, the recorder evaluates the cycles of the run's
traces that the run did not, and this can reach a trace the run did not. For
example: a register that is in reset to the end of the run does not use its
input, and a run of 2 cycles does not reach the third stage of a traced
pipeline.
