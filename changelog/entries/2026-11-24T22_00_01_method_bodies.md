# CHANGED
The warning that the plugin does not instrument the body of a class method
(`-Wx-circuit-context-uninstrumented`) is now given at the body of an
instance method or a class default, and only when that body loses
something: a local binding that the plugin would trace (or probe) in a
top-level function, or a component that `OPAQUE` asks for. It was given at
the class signature, for every class method with `HasCircuitContext` or
`HasProbe`. That signature needs the constraint, so that instances can call
instrumented code, and nothing silenced the warning: also not an instance
that only calls a top-level component, which is how to instrument a method.
`OPAQUE` on such a method is reported because the method does not become a
component, and Clash makes an HDL module of it for each call site.
