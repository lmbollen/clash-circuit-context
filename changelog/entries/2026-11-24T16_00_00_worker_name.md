# FIXED
An incremental build after an edit of a module compiled with the plugin no
longer fails with "Can't find interface-file declaration for variable `$wf`".
The worker that the plugin splits from a function is now a name that GHC's
interfaces can find. Before, an edit that left the module's interface as it
was, and a module recompiled in the same build that read the unfolding of a
module that was not recompiled, made the build fail until it was cleaned.
