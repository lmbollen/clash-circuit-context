# CHANGED
Duplicate names in a scope are numbered with `#`: two instances of a
component under one parent are `acc#0` and `acc#1` (before: `acc_0` and
`acc_1`), and so are the signals that two calls of a helper record into
their caller's scope. `_i` stays the structural position (an element of a
`Vec` or a tuple, an index of `imapComponents`), so a duplicate never looks
like an element, and its name no longer depends on which elements a test
evaluated.

# FIXED
A signal is never left out of a waveform because its name is already in its
scope. A name given as a string can contain `#`; when a number would give a
name that the scope already has, the duplicates get `##`, or more until no
name is taken. Before, the VCD, the FST and the sidecar showed one of two
signals with one name, with no warning.
